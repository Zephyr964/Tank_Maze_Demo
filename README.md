# Tank Maze Demo 坦克迷宫
Unity + C# 单机坦克小游戏Demo。具体代码存放在Assets中实践小项目的文件夹中

## 🎮 操作说明
- W / S：前进、后退
- A / D：坦克转向
- Shift：加速移动
- 鼠标左键：发射子弹
- ESC：打开设置面板，调节音量、开关音效音乐
- 拾取道具：血量恢复、在加粉道具拾取到7个时，子弹数会增加，通过碰撞拾取

## ✨ 实现功能
1. 迷宫：DFS随机生成迷宫地图
2. 敌人AI：随机移动，视野检测
3. 玩家坦克：移动、旋转、加速、射击逻辑
4. UI设置面板：音量滑块、音效开关
5. 存档：PlayerPrefs存储音量设置
6. 碰撞检测、子弹销毁、道具拾取系统

## 🛠 技术栈
Unity 2022, C#
DFS迷宫生成、UGUI、单例模式
